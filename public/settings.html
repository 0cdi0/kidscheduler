Kids

Each kid gets their own color and can be shown/hidden independently on the calendar. Deactivating a kid hides them from the calendar but keeps their history. "Class" (e.g. 1A, MSK) is used by appointment import to skip other classes' events — see Appointments below.

Groups

A group is a household side (e.g. "Philipp & Johannes"). The "other parent" label is used when a kid's day is left blank — it shows as "with <label>" instead of just empty.

School years

A school year auto-locks (read-only) once you add the next one and today has moved past its end date — it stays as a historical record. Unlock it here temporarily to fix a mistake.

Appearance

Pick the accent color used for public holidays and school breaks on the calendar (the legend swatch, day tinting, and text label all follow it). Leave a swatch on the default to use the built-in color.

Public holidays (Vienna, Austria)

Pulls official national/Vienna public holidays from the free date.nager.at service, plus Mother's Day & Father's Day (computed locally as the 2nd Sunday of May/June — they're not statutory holidays so that feed doesn't carry them). This does not cover school break periods (Ferien) — those aren't public holidays and have to be entered manually below, since there's no reliable free feed for them.

Appointments

One-off appointments per kid (doctor, school events, etc) — shown on the calendar and in each day's editor.

Bulk import

Both ways below end up at the same editable preview — nothing is added until you check it over and click Import. If the target kid has a Class set above, any row mentioning a different class or grade — a specific code ("Schwimmunterricht 3A") or a grade-level phrase ("für die 3.+ 4.Klassen", "Verabschiedung der 4. Klassen") — is unchecked by default, since a school notice like a class newsletter usually covers the whole school, not just one class. "alle Klassen" (all classes) always stays checked.

From CSV / Excel

Export the school's list to CSV (from Excel: File → Save As → CSV) with columns date, title, notes (dates as YYYY-MM-DD or DD.MM.YYYY).

From a scanned/photographed PDF

For a school notice that's a photo or scan (no selectable text) rather than a spreadsheet. Uses OCR on the server, so it needs poppler-utils and tesseract-ocr (+ German language data) installed there — see the README. OCR on a school flyer is never perfect — always check the preview row by row before importing.
